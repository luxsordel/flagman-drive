# FLAGMAN Drive — каршеринг электромобилей (пилот)

Рабочее название: **FLAGMAN Drive**. Компания: FLAGMAN GROUP. Город запуска: Минск.

Сервис поминутной аренды электромобилей с собственным автопарком. Клиент находит машину на карте,
бронирует, открывает её из приложения, едет и завершает аренду в разрешённой зоне.

Текущая стадия — **пилот без реальных машин**: телематика эмулируется, платежи и SMS — тестовые.
Цель пилота — показать руководству, что команда способна сделать качественный рабочий продукт.

## Что внутри

| Путь | Что это |
|---|---|
| `apps/api` | Бэкенд: Python, FastAPI, PostgreSQL/PostGIS |
| `apps/mobile` | Клиентское приложение: iOS, Android и веб из одного кода (Expo / React Native) |
| `apps/admin` | Веб-панель операторов и администраторов (React + Vite) |
| `services/car-emulator` | Эмулятор автопарка: «виртуальные машины» вместо телематических блоков |
| `packages/api-client` | TypeScript-клиент, генерируется из OpenAPI бэкенда |
| `infra` | Docker Compose, конфиги окружений |
| `docs` | Вся документация проекта |

> Папки `apps/*`, `services/*`, `packages/*` наполняются на этапе 0 (см. [дорожную карту](docs/05-roadmap.md)).
