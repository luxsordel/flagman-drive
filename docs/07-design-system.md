# 07. Дизайн-система

Основа — фирменный стиль FLAGMAN GROUP ([flagman-group.com](https://flagman-group.com/)):
строгий, надёжный, «инженерный». Для каршеринга добавляем живости: крупные карточки, карта на весь экран,
акцентные состояния (заряд, статус поездки).

Логотипы: [`docs/brand/`](brand/).

## Цвета (токены)

| Токен | Светлая тема | Тёмная тема | Где |
|---|---|---|---|
| `primary` | `#174B9B` | `#4C7FD0` | Кнопки, ссылки, активные элементы |
| `primary-strong` | `#073F82` | `#6B97DD` | Нажатие, логотип |
| `ink` | `#172236` | `#E8EDF5` | Основной текст |
| `ink-muted` | `#8D96A5` | `#8D96A5` | Второстепенный текст |
| `surface` | `#FFFFFF` | `#111D30` | Карточки |
| `background` | `#F4F7FB` | `#0B1424` | Фон экранов |
| `border` | `#DEE3EA` | `#24324A` | Границы, разделители |
| `success` | `#1E9E5A` | `#3CC27B` | Заряд в норме, поездка активна |
| `warning` | `#E59A1A` | `#F2B84B` | Низкий заряд, бронь истекает |
| `danger` | `#D23B3B` | `#F06464` | Ошибки, штрафы |

Тёмные значения — стартовые, подлежат проверке контраста (WCAG AA ≥ 4.5:1 для текста).

## Типографика

- Заголовки: **Oswald** 500–700 (как на сайте компании), без капслока в длинных строках
- Текст и интерфейс: **Open Sans** 400 / 600 / 700
- Цифры (цена, таймер, заряд): Open Sans с табличными цифрами (`tabular-nums`)

Шкала: 12 / 14 / 16 (база) / 20 / 24 / 32.

## Сетка и формы

- Отступы кратны 4: 4, 8, 12, 16, 24, 32
- Радиусы: 8 (поля), 12 (кнопки), 16 (карточки), 24 (нижние шторки)
- Минимальная зона нажатия — 44×44

## Источник правды

Токены живут в коде (`packages/design-tokens` после этапа 0) и используются мобилкой и админкой.
Этот документ описывает намерение; при расхождении правится код и документ одним PR.
