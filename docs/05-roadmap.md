# 05. Дорожная карта и бэклог

Итерации по 2 недели. Сроки ориентировочные — зависят от доступного времени команды.
Каждая итерация заканчивается чем-то, что можно **показать**.

Задачи этапов — в milestones на GitHub, рядом с пунктами указаны их номера. Пункт отмечается, когда закрыты
все его задачи.

## Этап 0. Фундамент (итерация 1)

Цель: пустое, но правильно устроенное приложение, которое собирается, тестируется и запускается одной командой.

- [x] Репозиторий на GitHub, защита `main`, доска Projects, метки, шаблоны
- [x] `infra/docker-compose.yml`: PostgreSQL+PostGIS, Redis, SeaweedFS (S3) (#2)
- [x] `apps/api`: каркас FastAPI (модули, конфиг, БД, Alembic, обработка ошибок, логи, health-check) (#3)
- [x] `apps/mobile`: каркас Expo (навигация, i18n ru/en, темы, дизайн-токены FLAGMAN) (#4)
- [x] `apps/admin`: каркас React + Vite (вход, макет, дизайн-токены) (#5)
- [x] `packages/api-client`: генерация клиента из OpenAPI; `packages/design-tokens`: токены для мобилки и админки (#6)
- [x] `services/car-emulator`: каркас (#7)
- [x] CI: линт, типы, тесты, сканеры безопасности для всех частей (#8)
- [x] Онбординг проверен «с нуля» на второй машине (#9)

**Демо:** `docker compose up` + приложение на телефоне показывает экран входа.
