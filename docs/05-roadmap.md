# 05. Дорожная карта и бэклог

Итерации по 2 недели. Сроки ориентировочные — зависят от доступного времени команды.
Каждая итерация заканчивается чем-то, что можно **показать**.

## Этап 0. Фундамент (итерация 1)

Цель: пустое, но правильно устроенное приложение, которое собирается, тестируется и запускается одной командой.

- [ ] Репозиторий на GitHub, защита `main`, доска Projects, метки, шаблоны
- [ ] `infra/docker-compose.yml`: PostgreSQL+PostGIS, Redis, SeaweedFS (S3)
- [ ] `apps/api`: каркас FastAPI (модули, конфиг, БД, Alembic, обработка ошибок, логи, health-check)
- [x] `apps/mobile`: каркас Expo (навигация, i18n ru/en, темы, дизайн-токены FLAGMAN)
- [ ] `apps/admin`: каркас React + Vite (вход, макет, дизайн-токены)
- [x] `packages/api-client`: генерация клиента из OpenAPI; `packages/design-tokens`: токены для мобилки и админки
- [ ] `services/car-emulator`: каркас
- [x] CI: линт, типы, тесты, сканеры безопасности для всех частей
- [ ] Онбординг проверен «с нуля» на второй машине

**Демо:** `docker compose up` + приложение на телефоне показывает экран входа.

## Этап 1. Вход и документы (итерация 2)

- [x] Вход по телефону + OTP (SMS в лог), JWT + refresh-ротация
- [ ] Профиль клиента
- [ ] Загрузка документов (права, паспорт, селфи) в приватное хранилище
- [ ] Админка: вход сотрудника с 2FA, роли, очередь KYC, одобрение/отклонение
- [ ] Журнал аудита

**Демо:** клиент регистрируется и загружает документы, оператор одобряет.

## Этап 2. Парк и карта (итерация 3)

- [ ] Модели машин, машины, статусы; сид-данные: 30 EV в Минске
- [ ] Эмулятор: позиции, заряд, приём команд, телеметрия вебхуками
- [ ] Зоны (PostGIS), редактор зон в админке
- [ ] Карта машин в приложении (MapLibre), карточка машины
- [ ] Карта парка в админке с обновлением в реальном времени (WebSocket)

**Демо:** живые машины на карте Минска в приложении и админке.

## Этап 3. Аренда (итерации 4–5) — ядро

- [ ] Тарифы и расчёт стоимости
- [ ] Бронь (15 мин бесплатно, таймаут фоновой задачей), отмена
- [ ] Открытие/закрытие с проверкой расстояния
- [ ] Осмотр с фото до и после
- [ ] Поездка: таймер, стоимость, режим ожидания
- [ ] Завершение с проверками (зона, двери, заряд), принудительное завершение оператором
- [ ] Тестовый платёжный провайдер: привязка карты, холдирование, списание, чек
- [ ] История поездок

**Демо:** полный сценарий аренды на телефоне — главная демонстрация руководству.

## Этап 4. Полировка пилота (итерация 6)

- [ ] Push-уведомления
- [ ] Чат поддержки, сообщение об инциденте
- [ ] Штрафы
- [ ] Задачи техникам (зарядка при низком заряде)
- [ ] Нагрузочный тест базовых сценариев, оптимизация
- [ ] Деплой демо-стенда, сборки для iOS (TestFlight) и Android (APK)
- [ ] Прогон чек-листа безопасности

**Демо:** презентация пилота FLAGMAN GROUP.

## После пилота (бэклог)

- Реальная телематика (выбор поставщика блоков для китайских EV)
- Реальная платёжка РБ (bePaid или аналог), реальный SMS-шлюз
- Пакеты часов/суток, промокоды, реферальная программа
- Автоматический KYC
- Точки зарядки на карте
- Публикация в App Store / Google Play
- Внешний пентест, юридическая проверка ПД
