# 01. Цели и границы MVP

## Зачем этот проект

**Бизнес-цель:** каршеринг электромобилей в Минске на собственном автопарке (китайские EV).

**Цель пилота (сейчас):** доказать FLAGMAN GROUP, что команда из двух человек с AI-ассистентами
может сделать надёжный, безопасный и расширяемый продукт. После одобрения — подключение реальных машин,
платежей и запуск.

### Критерии успеха пилота

1. Полный сценарий клиента работает end-to-end на iOS, Android и в вебе: регистрация → проверка документов →
   бронь → открытие машины → поездка → завершение → чек.
2. Оператор в админ-панели проверяет документы, видит парк на карте, управляет тарифами и зонами.
3. Эмулятор показывает «живые» машины в Минске: движутся, разряжаются, реагируют на команды.
4. Код проходит CI (линтеры, типы, тесты), покрытие доменной логики бэкенда тестами ≥ 80%.
5. Нет известных уязвимостей уровня High/Critical (сканеры зависимостей + чек-лист из [03-security](03-security.md)).
6. Новый разработчик поднимает проект локально по [онбордингу](06-onboarding.md) меньше чем за час.

## Не цели пилота

- Реальные машины, реальная телематика, реальные деньги, реальные SMS.
- Публикация в App Store / Google Play (сборки — только для демонстрации: Expo dev build / TestFlight позже).
- Масштабирование под тысячи одновременных поездок (но архитектура не должна это блокировать).
- Другие города, P2P-аренда, корпоративные клиенты, подписки.

## Пользователи и роли

| Роль | Где работает | Что делает |
|---|---|---|
| **Клиент** | Мобильное приложение / веб | Регистрируется, арендует машины, платит |
| **Оператор поддержки** | Админ-панель | Проверяет документы, ведёт инциденты, отвечает в чате, начисляет штрафы |
| **Техник** | Админ-панель (мобильная вёрстка) | Задачи на зарядку, мойку, осмотр; сервисный доступ к машине |
| **Администратор** | Админ-панель | Тарифы, зоны, автопарк, пользователи и роли, отчёты |

Права — по ролям (RBAC), все действия сотрудников пишутся в журнал аудита.

## Сценарии MVP (клиент)

1. **Регистрация и вход** по номеру телефона + одноразовый код из SMS (в пилоте SMS нет: при разработке код выводится в лог, на сервере пилота — общий код для заранее заведённых тестовых номеров).
2. **Проверка документов (KYC):** фото водительского удостоверения (обе стороны), паспорта и селфи с правами.
   Проверяет оператор вручную. Требования: возраст ≥ 21, стаж ≥ 2 года (настраивается).
   Архитектура допускает замену на автоматический KYC-сервис.
3. **Привязка карты** (тестовый платёжный провайдер; в бою — bePaid или аналог из РБ).
4. **Карта с машинами:** модель, фото, заряд батареи, запас хода, расстояние до клиента, тариф.
5. **Бронирование:** 15 минут бесплатно, далее платное ожидание. Отмена брони. Платное ожидание
   списывается и при отмене, и при истечении брони.
6. **Осмотр перед поездкой:** 4–8 фото машины, отметка повреждений. Фото хранятся как доказательство.
7. **Открытие/закрытие машины** из приложения — только рядом с машиной (≤ 50 м по геолокации).
8. **Поездка:** таймер, стоимость в реальном времени, «стоянка» (ожидание) по сниженному тарифу.
9. **Завершение аренды:** проверки — машина в разрешённой зоне, двери закрыты, фары выключены, «P».
   Фото после поездки. Списание, электронный чек.
10. **История поездок** и чеки.
11. **Поддержка:** чат с оператором, сообщение о ДТП / повреждении / проблеме.
12. **Уведомления:** push (бронь истекает, низкий заряд, поездка завершена).
13. **Языки:** русский и английский. Тёмная и светлая темы.

## Тарифы (по аналогам, настраиваются в админке)

- Поминутно в движении, поминутно на стоянке (дешевле), бесплатное бронирование 15 мин.
- Пакеты часов / суток — итерация 2.
- Штрафы: курение, грязь, парковка вне зоны, низкий заряд (< 10%) при завершении — настраиваемый справочник.
- Предавторизация (холдирование) суммы на карте при старте поездки.

Цифры тарифов — заглушки в сид-данных, реальные определит бизнес.

## Особенности электромобилей

- Машина недоступна для аренды при заряде ниже порога (по умолчанию 20%).
- Запас хода показывается клиенту; предупреждение, если до конца аренды может не хватить.
- Задачи техникам на зарядку создаются автоматически.
- Точки зарядки на карте (справочник, итерация 2).

## Сценарии сотрудников (MVP)

- Очередь проверки документов: одобрить / отклонить с причиной.
- Карта и список парка: статус, заряд, текущая аренда; ручные команды (открыть, закрыть, заблокировать).
- Поездки: просмотр, принудительное завершение, корректировка стоимости (с обязательным комментарием).
- Клиенты: просмотр, блокировка.
- Редактор зон на карте (полигоны: разрешено завершать / запрещено).
- Тарифы и штрафы.
- Журнал аудита.

## Глоссарий

| Термин | Значение |
|---|---|
| Аренда (rental) | Весь цикл от брони до завершения |
| Бронь (reservation) | Машина закреплена за клиентом, ещё не открыта |
| Поездка (trip) | Аренда после первого открытия машины |
| Телематика | Блок в машине: GPS, замки, датчики. В пилоте — эмулятор |
| Зона (zone) | Полигон на карте: где можно завершать аренду |
| KYC | Проверка личности и прав клиента |
