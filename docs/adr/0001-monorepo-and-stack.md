# ADR-0001. Монорепозиторий, FastAPI + Expo

- Статус: принято
- Дата: 2026-10-21

## Контекст
Команда из 2 человек на Windows 11, без Mac. Нужны iOS, Android и веб. Команда хочет Python на бэкенде.
Основную разработку ведёт AI (Claude Code), люди ревьюят — значит, стек должен быть популярным
(AI хорошо его знает) и читаемым.

## Решение
- **Один репозиторий** на весь продукт: бэкенд, клиент, админка, эмулятор, документация.
  Одна задача может менять API и клиент в одном PR; у Claude Code весь контекст в одном месте.
- **Бэкенд: Python 3.12 + FastAPI** — пожелание команды, async, автоматический OpenAPI.
- **Клиент: Expo (React Native) + TypeScript** — один код на iOS, Android и веб; облачные сборки EAS
  снимают необходимость в Mac.
- **Админка: React + Vite + TypeScript** — отдельно от клиента: другие пользователи, требования к
  безопасности и плотные таблицы, которые неудобно делать в React Native.

## Альтернативы
- **Flutter** — хорош для мобилки, но веб на Flutter слабее (тяжёлый, хуже доступность); язык Dart
  менее распространён, чем TypeScript.
- **Нативные Kotlin + Swift** — две кодовые базы, для Swift нужен Mac.
- **Django** — сильная админка «из коробки», но нам нужна своя админка с картой; FastAPI легче и типизированнее.

## Последствия
- В проекте два языка: Python (бэкенд, эмулятор) и TypeScript (фронт). Контракт между ними — OpenAPI.
- Карты в мобилке требуют dev build Expo (не работают в Expo Go) — см. ADR-0016 и онбординг.
