# ADR-0004. Хостинг пилота

- Статус: принято
- Дата: 2026-10-21

## Контекст
Бюджета нет. Есть GitHub Student Pack. Инфраструктуру Яндекса не используем. В пилоте нет реальных
персональных данных — только тестовые.

## Решение
1. **Разработка и демо — локально** через Docker Compose. Этого достаточно для презентации.
2. **Публичный демо-стенд** (когда понадобится) — один VPS в регионе ЕС на кредиты Student Pack
   (DigitalOcean или Azure for Students), Docker Compose + Caddy (автоматический HTTPS).
3. Всё упаковано в Docker-образы → переезд к любому провайдеру без переписывания.

## Альтернативы
- Kubernetes — избыточно для пилота.
- PaaS (Render, Fly.io и т.п.) — удобно, но бесплатные тарифы нестабильны; можно пересмотреть.

## Последствия
- Перед работой с реальными данными граждан РБ — юридическая оценка места хранения
  (Закон № 99-З) и, возможно, перенос в дата-центр в РБ. Docker-упаковка делает это переносом, а не переписыванием.
