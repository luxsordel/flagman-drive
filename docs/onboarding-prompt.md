# Промпт для онбординга через Claude Code

Новый участник копирует текст ниже целиком и вставляет его в **новую сессию** Claude Code
(приложение Claude → вкладка Code). Папку проекта выбирать не нужно: Claude сам склонирует репозиторий
и перейдёт в него.

Ручная версия тех же шагов — в [06-onboarding.md](06-onboarding.md).
Если промпт где-то сработал не так, поправьте этот файл через PR.

````text
Привет! Я новый участник проекта FLAGMAN Drive. Это пилот каршеринга электромобилей в Минске, и мы делаем его небольшой командой с помощью Claude Code. Репозиторий приватный: https://github.com/luxsordel/flagman-drive. Меня пригласили в него соавтором.

Помоги мне полностью подготовить компьютер (Windows 11) и разобраться в проекте. Действуй по шагам, после каждого шага коротко говори, что сделано. Если нужен я сам (вход в браузере, подтверждение, ввод данных), остановись и объясни, что именно сделать. Пароли и токены я в чат не вставляю, вход в GitHub только через браузер.

1. Проверь, что уже установлено: git, gh (GitHub CLI), uv, node/npm, Docker Desktop. Недостающее поставь через winget:
   - Git.Git
   - GitHub.cli
   - astral-sh.uv
   - OpenJS.NodeJS.LTS
   - Docker.DockerDesktop

   Используй флаги -e --accept-source-agreements --accept-package-agreements --silent. Docker большой, его ставь в фоне.

   После установки PATH в текущей сессии не обновится. Вызывай программы по полному пути (например, "C:\Program Files\GitHub CLI\gh.exe") или подгружай PATH из реестра. Если для Docker нужны WSL 2 или перезагрузка, скажи мне.

2. Настрой git. Спроси у меня имя и email для коммитов (email как в GitHub) и задай их глобально. Также выполни: git config --global core.autocrlf false (окончаниями строк управляет .gitattributes в репозитории).

3. Вход в GitHub. Открой мне вкладку терминала с командой
   gh auth login --hostname github.com --git-protocol https --web --scopes "project,read:org,workflow"
   и объясни, что нажать. Когда я скажу «готово», проверь через gh auth status. Если была ошибка 503 или сбой сети, просто повтори.

4. Найди приглашение в репозиторий luxsordel/flagman-drive (gh api user/repository_invitations). Покажи его мне и после моего «да» прими. Если приглашения нет, скажи, что его нужно попросить у владельца репозитория.

5. Склонируй репозиторий в %USERPROFILE%\Documents\flagman-drive и переведи эту сессию в эту папку. Убедись, что подхватились CLAUDE.md, .claude/settings.json и команды из .claude/skills (start-task, ship, review-pr, sync, project-status, demo, new-adr, weekly-update).

6. Прочитай README.md, CLAUDE.md и все файлы docs/ (включая adr/). Объясни мне простым языком:
   - что за проект, какая цель у текущего этапа и что считается успехом;
   - архитектура и стек: что где лежит и почему так решили;
   - главные правила безопасности и кода, которые нельзя нарушать;
   - как мы работаем: задачи → ветка → Claude Code → PR → ревью друг друга → squash merge, защита main, Conventional Commits, критерии «готово»;
   - какие есть общие команды Claude Code и когда их использовать;
   - что уже сделано и что дальше по дорожной карте (docs/05-roadmap.md).

7. Покажи текущее состояние на GitHub:
   - открытые задачи по вехам;
   - доску проекта (gh project list --owner luxsordel);
   - открытые PR и статус CI, отдельно PR, где ревьюером назначен я.

8. Если в репозитории уже есть код и docs/06-onboarding.md описывает запуск, подними проект локально по этой инструкции и проверь, что он работает.

9. Дай итоговый чек-лист со статусами (✅ готово / ⚠️ нужно моё действие): программы, git, вход в GitHub, доступ к репозиторию, клон, Docker запущен, проект запускается (если применимо), документы прочитаны.

10. Скажи, с чего мне начать:
    - если есть PR, где я ревьюер, начать с /review-pr <номер>. Отзыв публикуй только после моего подтверждения;
    - затем взять задачу с меткой "good first issue" (или "ready", если таких нет) командой /start-task <номер>;
    - всё, что на этих шагах было непонятным или не сработало, оформить правками в docs/06-onboarding.md и в этот промпт (docs/onboarding-prompt.md).

Ничего не пушь в main, не создавай и не меняй задачи и PR без моего подтверждения.
````
